1. Choose statement file (CSV or Excel)

Download a statement from your bank or card as CSV, XLS, or XLSX. It's parsed entirely in your browser — nothing is uploaded anywhere. Password-protected Excel files are supported — you'll be prompted to unlock them. For PDF-only statements, use the CSV/Excel export option in net-banking instead.

2. Map columns

Many bank CSVs have a few junk rows on top (name, address, statement period). The header row below is auto-detected — check the preview and adjust if the column names look wrong.

Analysis setting

Respect opening dates (toggle in the top bar): when on, transactions dated before an account's opening date are hidden everywhere — excluded from balances, dashboards, net worth, and the Transactions list. They remain in the database (turn the toggle off to see and count them again). Turn it off to include every transaction regardless of date.

In Groww → Stocks/Mutual funds → export/download your holdings as CSV. This replaces all Groww-imported holdings with the latest file (your manually-added FDs are untouched). No login — you export, this reads the file locally.

Groww files have Personal Details / Summary rows on top — set the Header row to the line with the actual column names (Stock Name, Quantity, Current Value…).
